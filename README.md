# C and Python Basics

A simple programming project demonstrating basic output in C and Python.

## Programs

- **Demo.c:** Prints Hello, World!
- **demo.py:** Prints Sagar

## Requirements

- A C compiler to compile and run Demo.c
- Python 3 to run demo.py

## Run the Python program

```bash
python demo.py
```

## Compile and run the C program

```bash
gcc Demo.c -o Demo
```

On Windows, run the compiled program using:

```bash
.\Demo.exe
```
